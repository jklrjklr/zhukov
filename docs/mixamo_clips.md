# Mixamo clips to download

Site: https://www.mixamo.com (Adobe login). Any default character is fine (e.g. "Y Bot");
only the motion is used, retargeted onto our rig in Blender.

## Download settings (every clip)

- Format: **FBX Binary (.fbx)**
- Skin: **Without Skin** (for ONE clip, e.g. Rifle Idle, also download **With Skin** once)
- Frames per Second: **30**
- Keyframe Reduction: **none**
- **In Place: ON** whenever the checkbox exists (the game moves the character)

Search by the name below; if the exact name is missing, take the closest one and keep the
file name telling what it is. Names in *italics* are optional.
