# Sound slots

Every sound is a named slot: `audio/<slot>.ogg` (or `.wav`). Variants `<slot>_1.ogg`,
`<slot>_2.ogg` ... are picked at random. A missing slot is silent (or borrows another slot,
see `ALIASES` in `scripts/sfx.gd`). To replace a sound, drop a file with the same name here.

Format: Ogg Vorbis, 44.1 kHz, mono for SFX, stereo for music/ambience. Total size is under 8 MB.

Everything here is regenerated by `tools/mkaudio.py` (needs ffmpeg + the unzipped Kenney packs,
see the header of that script). `gd --headless -s res://tools/audio_coverage.gd` checks that every
slot used in code (and in the spec's shared slot list) has a file; it exits 1 if one is missing.

Source key: **S** = synthesized with ffmpeg (layered transient + body + tail, EQ, compression),
**K** = trimmed/processed Kenney sample (CC0), **S+K** = both layered.
